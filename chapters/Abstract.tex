\begin{itemize}
The deployment of large language models is increasingly constrained by
their high memory and computational requirements, while aggressive
low-bit quantization can introduce substantial degradation in model
quality.  For these issues, this dissertation presents a comparative
post-training quantization study of Llama-3.2-3B-Instruct using AWQ,
SmoothQuant, a project-specific W4A8 pipeline and NestQuant. All
principal configurations are evaluated under a common UltraChat-200k
protocol, while additional NestQuant ablation and packed-deployment
experiments are performed to examine the effects of activation and
KV-cache quantization. The results show that SmoothQuant achieves the
best quality retention, while packed W4 configurations reduce the most peak GPU memory. NestQuant further demonstrates that activation
quantization is more quality-sensitive than KV-cache quantization. Overall, the results demonstrate
that practical low-bit LLM quantization requires a joint consideration
of model quality, memory reduction, quantization scope and deployability.

\end{itemize}

\begin{itemize}
Large language models can require large amounts of computer memory,
making them expensive and difficult to run on hardware with limited
resources. This project compared several methods for reducing the
numerical precision of a large language model in order to lower memory
requirements while preserving model performance. The study examined how
different approaches affected model quality, storage size and graphics
processor memory usage.

The results showed that no single method was best in every respect.
Some methods preserved model quality better, while others achieved
greater memory savings. The study also found that reducing the precision
of model activations had a stronger effect on performance than reducing
the precision of stored attention information. Overall, the work shows
that efficient deployment of large language models requires balancing
model quality, memory savings and practical hardware requirements.
\end{itemize}
