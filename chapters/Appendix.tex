\chapter{A.Experimental Configuration}
This appendix records the retained experimental configuration used for
the principal results reported in this dissertation. Its purpose is to
provide the implementation-level settings required to interpret and
reproduce the final experiments while distinguishing them from earlier
development and diagnostic runs.

All principal experiments use
\texttt{meta-llama/Llama-3.2-3B-Instruct} as the common source model.
The source checkpoint is represented using BF16 parameters and provides
the full-precision reference for the cross-method comparisons. The main
experiments were executed on a single NVIDIA GeForce RTX~5090 using
CUDA~12.8, PyTorch~2.11.0 and Transformers~5.10.1.

The common model-quality evaluation follows an assistant-response-only
scoring protocol. User turns and preceding conversational context remain
available as model input, but only assistant-response positions
contribute to negative log-likelihood and perplexity. Dataset loading
and tokenisation are excluded from the measured execution region.

Across the 28 decoder layers, this corresponds to 196 target Linear modules and
2,818,572,288 target weight elements. Embeddings, normalisation
parameters, the language-model head and other non-target tensors remain
outside this common Linear-layer quantization scope unless explicitly
stated otherwise.
